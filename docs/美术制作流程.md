# 首版美术制作流程

以已认可的五份原创试制为视觉基准，按简笔可玩版、真实参考素材册、原创替换版三阶段交付。沿用 Taro + React 和现有首版经营规则。

## 界面与交互

- 柜台：状态栏、热销类别、店铺场景、顾客半身像、对白、来货/求购、鉴定与交易、交易小票。
- 仓库：分类筛选、商品网格、商品档案、上架/撤下、清仓确认。
- 升级：店铺等级、仓库容量、展示位，固定升级位置。
- 账本：周租、欠租补缴、交易流水。
- 辅助状态：手册、重开确认、空仓、无合适商品、资金不足、仓位不足、存档故障。

主场景采用正面柜台构图，顾客为画面主体；店铺背景、人物、终端分层，方便逐项替换。文字、按钮、边框和表格使用跨端组件绘制，不制作图片文字。

## 31 项素材范围

24 件商品、4 类顾客、1 张店铺背景、1 个交易终端、1 个鉴定工具。每项只有一个稳定编号，贯穿简笔、Unity 参考、原创原稿和运行时图片。商品名、价格、顾客预算、租金和存档格式沿用现有规则。

素材参考按外形与用途选择，与《商品数值对照》的价格档位来源分开记录，避免把“同价位映射”当成物品身份。原作素材仅保存在本地参考册目录；产品使用原创图。

## 规格

- 延续已认可试制的低饱和灰蓝、暗紫阴影、奶油色高光、旧金属与磨损材质。
- 物品完整居中、透明背景、无文字；人物正面半身自然比例，不使用 Q 版。
- 运行时商品画布 128×128、人物 320×400、终端 256×224、鉴定工具 128×128、背景 960×640。
- 高清生成原稿单独保存；运行时采用等比例缩放和透明留白，不拉伸、不直接覆盖原作像素。小屏展示优先清楚可辨。
- 参考册记录实际来源、Path ID、原始尺寸、对应新设计、使用界面和制作状态。
