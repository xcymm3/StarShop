# v0.3 经济与流程设计

24项基础价保留在 `商品数值对照.json`。其中多数是价位/用途借鉴，并不是同一物品：例如咖啡豆的70引用原作模块价，不能据此称为原作咖啡定价。v0.3没有以这张表代替完整经济规则验证。

| 关系 | 当前设计 |
|---|---|
| 商品价值 | 基础价×品质(1/1.5/2.2)×状态(0.6/0.85/1)，取整数 |
| 未知信息 | 品质未揭示时只给普通至稀有的参考范围；收购不自动揭示 |
| 卖家报价 | 按卖家声明品质、已知状态与0.62～1.25倍报价生成；声明可以高于真实品质，因此可能买贵 |
| 鉴定 | 一件8币，买前买后均可，仅揭示，不刷新报价 |
| 买家报价 | 船员1.05/商人0.9/收藏家1.22×价值，今日热销再×1.15；预算不足不能成交，不把报价自动压到预算 |
| 独立预算 | 船员60～200×等级，商人100～420×等级，收藏家180～850×等级；不读库存价值兜底 |
| 偏好 | 独立类别；收藏家要精良以上且不损坏；船员和商人接受普通/损坏；同客共享预算和数量 |
| 展示 | 有展示品时，55%概率以展示品类别决定买家所求类别；不保证来买，也不生成相等预算 |
| 还价 | 每客一次10%请求；可接受、拒绝或离开。成交声望+1，拒绝还价-1，因还价离开-2，声望限0～100 |
| 成长 | 15笔且声望45达二级，40笔且声望55达三级，解锁更高价货；升级须实际付款 |
| 占地 | 不同商品1×1～2×3；较大货占空间，真实碰撞影响收货与展示 |
| 日程 | 一次确认一笔，批量仍一笔；五笔日结；拒绝、鉴定、整理、清仓不计笔数 |
| 周租 | 第七日结束出120账单，主动付款或明确延期。欠租始终保存，退出不额外计租 |
| 恢复 | 有货可按已知/保守估价45%清仓；低资金空仓时提供可负担来货；低于5且空仓可完成20币理货劳动 |

预算上限只提高可遇见范围，不保证高价货立即成交。选择高价、品质未知或占地大的货，都会增加压货风险。当前不加入腐坏和现实时间压力。

## 已验证与限制

规则测试证明原价映射一致、存在高于真实价值的卖家报价、相同随机状态下买家预算不因替换库存价值而改变。三个正常新局已验证35笔到第八天并交首租。浏览器另从新局正常通过同一接口完成一周。

这证明短期流程可完成，不是长期经济平衡证明。有限种子不能代表所有玩家策略；理货恢复用于避免软锁，不保证盲目收货也能盈利。所有上述倍率、面积、预算和租金均是手机简化版规则，不冒充原作精确参数。
